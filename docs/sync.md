# Tie 同步逻辑

用户日常只感知 **保存**。同步是保存之后的系统行为，成功时无感；失败或冲突才轻量提示。

相关格式见 [`page-format.md`](./page-format.md)。导出闭包包（按引用带走一撮页面）**不是**同步通道，见 [`page-format.md`](./page-format.md#页面闭包导出--导入tie-export--tie-import)（`tie export` / `tie import`）。

## 连接状态

用户只看到两种状态，没有「存储源」：

| 状态 | 含义 |
|------|------|
| **本地** | 工作区。可以绑定多个本地文件夹（含 SMB 挂载目录）。页面写在这些工作区里。 |
| **本地 + 服务器** | 在本地之上只绑定一台服务器。绑定后保存会云同步。 |

- 服务器同时只绑定一台。解除绑定后回到本地。
- 每个本地工作区在服务器上各有一份对应副本，用来同步，不作为用户可再添加的工作区。
- **独立直连 S3 已废弃**（不再提供添加入口；存量只读兼容）。S3 只是服务器的存储能力。
- 文档层只认标准树；同步协议不按页双写多套 adapter。

## 保存 vs 同步

| 动作 | 行为 |
|------|------|
| **保存** | 写入当前工作副本（本地/SMB 路径，或经后台 API）。本机/主通道落盘成功即保存成功。 |
| **同步** | 保存成功后自动对齐对端。未配置对端则跳过。 |

流水线（对用户折叠为一次保存）：

1. 写入工作副本  
2. 若已配置对端 → 自动对齐（Git 或后台）  
3. ② 成功 → 界面仍只显示「已保存」  
4. ② 失败 → **仍算已保存**；轻量提示「尚未同步到其他设备」，可稍后重试或安装同步组件  

## 同步矩阵

| 场景 | 机制 | 何时跑 |
|------|------|--------|
| 本机/SMB ↔ 其他副本（含 SMB 上的 bare、Git 托管） | **Git** commit + fetch/rebase/push | 保存后自动（可 debounce）；启动/回前台可静默 pull |
| 本机 ↔ 后台工作区 | **后台 API**（服务端再写磁盘或 S3） | 保存即写后台；回前台静默拉取 |
| 后台磁盘 ↔ 后台 S3 | 仅服务端配置，客户端无感 | 运维切换 |
| 分享 / 迁移子集 | **export 闭包包** | 用户显式导出，不建立持续同步 |

## Git 运行时（桌面）

- **安装包不自带 Git。**
- 解析顺序：`TIE_GIT` → 应用数据目录已下载的运行时 → 系统 `PATH` 中的 `git`。
- 需要同步且找不到 Git 时：提示下载同步组件（Windows 可一键拉取 MinGit 到应用数据目录）；或打开说明中的下载链接。装好后继续静默同步。
- UI 不把「Git」当主功能名；高级设置里配置「多设备同步」remote 即可。
- Android / 无桌面环境：不跑 Git，只走后台或本地目录。

## 冲突

| 通道 | 第一版策略 |
|------|------------|
| Git | `pull --rebase`；冲突则 abort，保留本地提交；用户侧文案避免 rebase 术语 |
| 后台 | 版本/内容不一致时提示选边或对比；不静默按页自动合并 |

手动「同步并载入」仅为排障/高级，不是日常主路径。

## 与 MCP / Agent

- MCP/`tie` CLI 读写的是某一份工作区树；写入等价于保存，随后走同一套自动对齐（若该环境配置了对端）。
- 在线 MCP 服务器应挂一份工作区；与笔记本对齐靠 Git remote 或同一后台，而不是 MCP 协议本身做同步。

## 退役中的旧行为

- 客户端直连 S3 增量同步作为主路径（添加入口已移除）  
- 「同步到备份镜像」按页推送作为默认能力（UI 已隐藏）  
- 以 frontmatter `storage_source_ids` 驱动多源扇出保存（新写入已省略该字段）  

## 相关能力

- **导出闭包**：`tie export` / MCP `tie_export` / 编辑器「⇪」— 见 `page-format.md`（子集分享）  
- **整树携带**：`.tie` 解决方案 + 目录树；可选 `.tiez`（`tie pack` / `tie unpack`）  
- **后台 MCP HTTP**：随后台启动（`TIE_MCP_HTTP=1`）。没绑后台时 Agent 直接调用本机 `tie`，不另起 HTTP  
- **只读 Web**：浏览器打开 `#/read/<pageId>`  
- **Agent 变更**：`.tie/audit/events.jsonl`；右侧栏「变更」Tab
